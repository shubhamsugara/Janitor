# Phase 3b Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add rules R6, R7, W1, W2, W3, W5, "select all N matching", the name/source filters, a help panel with Info links, and a first-run walkthrough.

**Architecture:** Cross-resource rules get a pure `RuleContext` built once per scan from stored rows, so policy edits still apply at startup without a rescan. Select-all is resolved on the server from the same filter dict the list route uses. Help text comes from `/api/meta`; the panel and the tour are small in-repo components.

**Tech Stack:** Python 3.12, FastAPI, SQLite, boto3/moto; React 19, TS, Tailwind 4, Radix, Vitest.

**Spec:** [`docs/superpowers/specs/2026-10-08-phase-3b-design.md`](../specs/2026-10-08-phase-3b-design.md)

## Global Constraints

- Public repo: fake IDs only (12 identical digits); `make test` runs the leak check.
- Read-only: no new non-`Describe/List/Get` call; locks unchanged.
- No new dependencies.
- Copy: sentence case, verbs on buttons, no "successfully", "please", `!`; errors say what happened, then what to do.
- Status/rule wording comes from `rules.py`/`definitions.py` via `/api/meta`, never hardcoded in the UI.
- `linker.py`, `normalize.py`, `graph.py`, `rules.py` do no I/O.
- Tests first; commit with `make test && git commit` (never `;`).

## Review Focus

1. An AMI name with regex-special characters or no version suffix — groups as its whole name; R6 message stays readable. (Task 2 test `test_r6_unmatched_name_is_its_own_group`.)
2. A user regex that is catastrophic or invalid in the filter — invalid → 400 with the message; regex errors never 500. (Task 4 test `test_bad_name_regex_is_400`.)
3. Select-all while a scan finishes — the plan resolves against the scan current at plan time and records it; simulate's existing 409 covers a later change. (Task 5 test `test_selection_resolves_against_current_scan`.)
4. Walkthrough on a page with no rows — the card shows centered, no crash. (Task 9 test "shows the step without an anchor".)
5. Help opened on top of the resource drawer — closing help leaves the drawer open. (Task 8 test "closing help keeps the drawer".)

Rule texts (RULES order R1–R7, then W1–W7):

- W5 "Shared RDS snapshot", warn: "Other accounts can restore it. They lose access when it is deleted." Message: `"It is public."` when `"all"` in shared_with, else `f"Shared with {join_and(accounts)}. They lose access to it."`
